# Fairground - low poly

Model by Brian Trepanier. [Original model on Sketchfab](https://sketchfab.com/3d-models/fairground-low-poly-9ed8924d8a67411d96cb2236d9a426d1) · [Artist profile](https://sketchfab.com/CMBC) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

This edition applies the glTF node transforms, combines the mesh sections into a Y-up OBJ, converts its UVs, and stores the Base Color map as WebP at up to 2048 pixels.
